# windows_rds

На узле сеансов ставит роль узла сеансов. На посреднике (`windows_rds_deploy`) собирает ферму из двух узлов, веб-доступ и сервер лицензий. Ключ лицензий сюда не подставляется: работает льготный срок, пока лицензии не куплены. Профиль пользователя эта роль не копирует, его держит windows_fslogix.
