# windows_ad_ds

Ставит роли AD DS и DNS. Первый контроллер `ad.rusagricom.ru` поднимается, когда включён `windows_ad_ds_promote`. Второй становится репликой, когда включён `windows_ad_ds_replica` и заданы пароль администратора домена и пароль режима восстановления. Оба флага сразу включать нельзя. Внешние имена уходят на `windows_ad_ds_dns_forwarders` (офисный резолвер). Пароли в репозиторий не кладутся.
