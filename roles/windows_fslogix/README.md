# windows_fslogix

Кладёт установщик FSLogix в SYSVOL и публикует политику на OU рабочих станций и OU фермы. Политика включает контейнер профиля на отдельной шаре и ставит программу при запуске компьютера. Пока компьютер не перенесён в эти OU, политика его не касается. На узлах фермы программа ставится сразу, когда `windows_fslogix_install_agent` включён.
