# truenas_profiles

Создаёт на TrueNAS датасет и шару `profiles`, отдельно от шары сканирования. Если задан пароль администратора домена, подключает каталог к `ad.rusagricom.ru`, чтобы контейнеры профилей получили доменные права. Пароли в репозиторий не кладутся. Шара сканирования этой ролью не меняется.
